# 辩论演练室

**[公开网站：真实演练只读预览](https://randomclb.github.io/debate-strategy-wg-57c5d8b4/)** · **[完整交互版本机入口](http://127.0.0.1:56615/)**

新版是真实模型驱动的辩论模拟器：按题检索公开资料、读取候选正文、比较正反论点，与真人逐轮交锋或观察 AI 正反对练，最后对实际发言进行独立复盘。不是固定模板填空。

## 两种入口的区别

GitHub Pages 只能托管静态文件。公开网站展示两场已保存的实际演练，支持查看交锋、论点核查、来源、独立复盘和导出；不会根据新输入生成内容，也没有公开模型后台。

**开始新辩论、继续对话和实时搜索，需要运行本机交互版。** 公开首页提供该入口。127.0.0.1 指向打开浏览器的设备，手机上不能以此连接 Mac。没有部署公共隧道，也没有上传模型凭据。

## 在已有 Hermes 环境的 Mac 上运行

1. 下载本仓库 ZIP 并解压，进入 `simulator` 目录；或克隆本仓库。
2. 双击 `启动辩论演练室.command`，或在该目录运行 `python3 server.py --port 56615`。
3. 打开 http://127.0.0.1:56615/，填写自己的论题、立场、受众以及可选材料。

需要 Python 3，以及已配置好的本机 Hermes、ChatGPT 订阅连接、公开网页搜索与正文提取工具。适配的是当前已有工作组环境，包括请求前执行策略接口；普通全新 Hermes 安装尚未验证，不宣称开箱即用。

## 使用

- 选择自己与 AI 对辩，或 AI 正反对练。发言直接进入下一轮，模型须回应对手真实原话。
- “论点与核查”显示具体推理、最脆弱的前提、原文核对及待核事项；“来源资料”提供候选网页。
- “复盘当前交锋”评议双方实际发言，列出遗漏的问题、共情效果和可直接使用的改进回应。新增发言使旧复盘退出当前版本。
- 停止后保存已有记录；继续沿用同一场和累计记录。每个明确指令的本地上限为320次请求/120分钟，不是项目总额度。

模型为 GPT-6 Sol / high，调用和凭据留在服务端。记录存于本机 `simulator/.data/`，已排除提交。公网仅包含合成测试题的演练输出及来源链接；不包含私有聊天、数据库、网页正文存档、配置或凭据。

## 证据边界

实测题为课堂手机保管和每周两天混合办公。复盘识别了“手机可能分心→无条件没收包括医疗用途”的推理跳跃，也指出了把“允许试行”偷换为默认推广的问题。两场内容得到新的独立模型上下文评议；不是所有题目的通用可靠性保证。

部分交锋轮次有重复；混合办公的多个网页主要来自同一项试验，不能算多项独立证据。摘录匹配不代表研究或结论必然正确。公开预览不分发来源正文存档。

## 目录

- 根目录：GitHub Pages 只读预览。
- `simulator/`：完整本机交互应用和启动脚本。
- `examples.json`：脱离个人环境的合成测试演练，不是实时 API。
- `debate-simulator-local.zip`：本机应用源码下载，不含历史数据库或凭据。

旧版静态策略器保留在 Git 历史中，可恢复。
